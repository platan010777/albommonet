WILDBERRIES

🟪 Скрипты Wildberries

Инструменты для работы с выгрузками WB: сравнение магазинов по названию, по артикулу и умным матчингом, сводка и перенос цен, сравнение с другими площадками.

📦 Сводка WB: 2 файла → 1 таблица

Соединяет «Общие характеристики» + «Обновление цен» по nmID. Получаете плоскую таблицу: артикул, nmID, название, цена.

WB · сведение

📊 Сравнение WB ↔ WB по названию

Сравнивает два магазина WB по названию товара. Хорошо ловит одинаковые товары, даже если артикулы разные.

WB · сравнение

🎯 Сравнение WB ↔ WB по артикулу

Сравнивает два магазина WB по артикулу продавца. Быстрее и надёжнее, если артикулы в магазинах совпадают. Порог схожести ловит опечатки.

WB · сравнение

🎓 Сравнение WB ↔ WB — SMART-PRO

Двухпроходное сопоставление: сначала по артикулу (порог 90 %), затем по названию (порог 50 %) для тех, кто не склеился. Скрипт сам чистит склеенные артикулы WB.

WB · смарт-матчинг

📥 Перенос цен из образца

Берёт цены из готового «правильного» файла и подставляет к товарам второго магазина WB. Двухпроходный матчинг: артикул 90 % → артикул 50 %.

WB · перенос

📊 Сравнение Ozon ↔ WB

Сопоставьте товары между Ozon и Wildberries по названию — получите отчёт с ценами обоих маркетплейсов и разницей.

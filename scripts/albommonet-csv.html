🧾 Обработка CSV магазина ALBOMMONET

Убирает дубликаты и мусорные строки из CSV-выгрузки магазина, оставляет 5 нужных колонок в правильном порядке. Файл готов к дальнейшему сравнению с маркетплейсами.

🔒 Всё считается прямо в браузере.
🛡️ Названия колонок находятся автоматически по синонимам. Кодировка UTF-8, разделитель ; — определится сам.

📋 Что делает скрипт

  1. Читает CSV магазина (UTF-8, разделитель ;).
  2. Находит колонки по названиям: Наименование, Код артикула, ID артикула, Зачеркнутая цена, ID товара.
  3. Удаляет строки с пустым «ID артикула» — это дубликаты и мусор от недоделок движка сайта (включая строку category;АКЦИЯ).
  4. Собирает результат в порядке: ID артикула → ID товара → Наименование → Код артикула → Зачеркнутая цена.
  5. Отдаёт xlsx и csv для дальнейшей работы.

🗑️ Почему удаляются строки с пустым «ID артикула»

Движок сайта иногда отдаёт CSV с мусором. Проявляется это так:

  • Есть строка category; АКЦИЯ; ... — это не товар, а служебная категория. ID артикула пустой.
  • Бывают товары-дубликаты: у одного есть ID, у второго пусто.

Пример

Тип строки Наименование ID артикула Статус
category АКЦИЯ (пусто) 🗑️ удаляем
product_variant "Асидол". Средство для чистки монет 1148 ✅ оставляем
💡 Правило простое: пустой «ID артикула» = мусорная строка. Реальный товар всегда имеет ID.

🎯 Матчинг 1С — АльбомМонет

Загрузи два файла — скрипт сам определит, где ОБЩИЙ (с ценами), а где БЕСЦЕННЫЙ (без цен). В последний допишет Номенклатуру и Наименование из ОБЩЕГО.

🔒 Всё считается прямо в браузере. Файлы никуда не отправляются.

1Загрузи два файла

Порядок не важен — скрипт сам определит роли по наличию колонки со словом «Цена». Файл с ценой = ОБЩИЙ (оттуда возьмём), файл без цены = БЕСЦЕННЫЙ (в него пишем).
💡 Если шапка не в первой строке — поменяй «Строка заголовков» на 1, 2 или 3. Скрипт также пробует автопоиск.

2Настройки колонок (можно оставить как есть)

Скрипт ищет колонки в обоих файлах автоматически по этим именам. Если по-другому — впиши точное название.
Можно несколько вариантов через запятую — скрипт выберет тот, что найдётся.
Если в заголовке колонки есть это слово — файл считается ОБЩИМ. Регистр не важен, «ё» = «е».

3Очистка артикулов (применяется к ОБОИМ файлам)

Проход 1: убираем дублированный префикс без разделителя, СОХРАНЯЯ хвост.
Проход 2: убираем выбранные суффиксы с конца (без учёта регистра).
Проход 3: если слэшей больше порога — убираем слева всё до второго «/» включительно.
Проход 4: убираем висячие «/» на конце.
Проход 5: нижний регистр + убираем пробелы.
Пример: lb2-proflb2-profпрозрачный → lb2-profпрозрачный
Пример: ЛББ-12/Д/ЛББ-12/Д/Черный/НТ → лбб-12/д/черный

🎯 Сравнение WB ↔ WB — умный матчинг WILDBERRIES

Двухпроходное сопоставление товаров двух магазинов WB: сначала по артикулу (порог 90 %), затем — для несовпавших — по названию (порог 50 %). Скрипт чистит склеенные артикулы WB.

🔒 Всё считается прямо в браузере. Файлы никуда не отправляются.
🛡️ Скрипт умеет чистить склеенные артикулы WB (например, LB1-ProfLB1-ProfПрозрачный → LB1-Prof).

📋 Что загружаем и в каком порядке

  1. Магазин №1 — 2 файла: «Общие характеристики» + «Обновление цен».
  2. Магазин №2 — 2 файла: «Общие характеристики» + «Обновление цен».
  3. Жмём кнопку — скрипт сам склеит каждый магазин и сопоставит их по артикулу, затем по названию для несовпавших.

💡 Промежуточные файлы сохранять не нужно — всё считается в браузере.

🎯 Как работает двухпроходный смарт-матчинг

Скрипт сопоставляет товары в два прохода:

Проход 1 — по артикулу (порог 90 %)

WB иногда отдаёт артикул в «склеенном» виде. Скрипт это чистит:

Что отдаёт WBПосле очистки
LB1-ProfLB1-ProfПрозрачный LB1-Prof
АБ-10Б/АБ-10Б/Бордовый АБ-10Б
АП-97ПАП-97ПГолубой АП-97П
ЛМ48-5_Prof ЛМ48-5_Prof (не меняется)
✅ LB1-Prof ↔ LB1-ProfLB1-ProfПрозрачный → 100 %

Проход 2 — по названию (порог 50 %)

Для тех товаров, что не склеились по артикулу (например, если у одного и того же товара в двух магазинах разные артикулы продавца):

✅ АБ-10Б-Б (магазин 1) ↔ АБ-10Б/АБ-10Б/Бордовый (магазин 2) → ~55 %

Колонка «Способ» в отчёте

  • 🎯 по артикулу — точно (или с мелкими различиями)
  • 📊 по названию — пара найдена по названию (проверь глазами)
💡 Совет: если по названию много склеек, но они «серые» — отфильтруй в Excel по колонке «Способ» = «📊 по названию» и проверь вручную.
❓ Что делать, если WB переименовал колонки

WB любит менять названия колонок в выгрузках. Скрипт это предусмотрел: он ищет нужные данные по списку синонимов. В 99 % случаев ничего делать не надо.

Если WB придумал что-то совсем новое

  1. Открой файл WB и посмотри, как точно называется колонка.
  2. Впиши это название в соответствующее поле выше.
  3. Запусти скрипт — ручное название имеет приоритет.

Колонка «Способ»

  • 🎯 по артикулу — пара найдена в первом проходе (максимальная уверенность)
  • 📊 по названию — пара найдена во втором проходе (проверяй глазами)

Если увидишь много «нет пары»

  • Снизь порог 1 до 80 % — склеится больше артикулов.
  • Проверь: если менеджеры пишут артикулы по-разному в двух магазинах, поможет порог 2 (название).
  • Если товары в двух магазинах — совсем разные — так и должно быть.
📘 Как работает этот скрипт

Что делает

  1. Принимает 4 файла WB (2 магазина × 2 файла).
  2. Внутри каждого магазина склеивает характеристики + цены по nmID.
  3. Проход 1 — сопоставляет товары двух магазинов по артикулу продавца с порогом 90 %.
  4. Проход 2 — для несовпавших сопоставляет по названию с порогом 50 %.
  5. Считает разницу цен и выдаёт Excel-отчёт.

Технические детали

  • Шапка ищется в первых 10 строках каждого листа.
  • Скрипт пробует все листы и выбирает тот, где больше совпадений.
  • Чистка артикулов: убираем склейки (AB-12AB-12Цвет → AB-12).
  • Нормализация артикулов для сравнения: нижний регистр, только буквы-цифры.
  • Дубликаты nmID отбрасываются.
  • Сравнение — по коэффициенту Dice + бонус за совпадение длины.

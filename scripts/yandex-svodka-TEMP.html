🟡 Яндекс.Маркет — сводка двух магазинов YANDEX

Берёт файл Я.Маркета (лист «Список товаров»), разделяет товары на два магазина (по числовому / буквенному SKU) и сводит их в плоскую таблицу по названию: сначала точное совпадение, затем нечёткое (порог 70 %).

🔒 Всё считается прямо в браузере. Файлы никуда не отправляются.
🛡️ М1 = SKU только цифры. М2 = SKU содержит буквы.

📋 Что загружаем

  1. Один файл .xlsx из ЛК Яндекс.Маркета — «Базовые цены и минимум для акций».
  2. Нужен лист «Список товаров». Скрипт найдёт его сам.
  3. Внутри будут колонки: Ваш SKU, Название товара, Цена, Зачёркнутая цена.

💡 Файл читается один раз. На выходе — плоская таблица с парами М1 ↔ М2 и «сиротами».

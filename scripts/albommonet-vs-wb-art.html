🎯 Как работает двухпроходный матчинг

Скрипт сопоставляет товары в два прохода:

Проход 1 — по артикулу (порог 90 %)

WB иногда отдаёт артикул в «склеенном» виде. Скрипт это чистит:

Что отдаёт WBПосле очистки
LB1-ProfLB1-ProfПрозрачный LB1-Prof
АБ-10Б/АБ-10Б/Бордовый АБ-10Б
АП-97ПАП-97ПГолубой АП-97П
ЛМ48-5_Prof ЛМ48-5_Prof (не меняется)
✅ LB1-Prof ↔ LB1-ProfLB1-ProfПрозрачный → 100 %

Проход 2 — по названию (порог 50 %)

Для тех товаров, что не склеились по артикулу (обычно из-за цвета в WB-артикуле — он там не выделен):

✅ АБ-10Б-Б (сайт, «бордовый») ↔ АБ-10Б/АБ-10Б/Бордовый (WB) → ~55 %

Колонка «Способ» в отчёте

В итоговом файле будет колонка, где указано, каким проходом нашли пару:

  • 🎯 по артикулу — точное совпадение или мелкие различия (100 % — самый надёжный)
  • 📊 по названию — пара найдена по названию (проверь глазами)
💡 Совет: если по названию много склеек, но они «серые», — отфильтруй в Excel по колонке «Способ» = «📊 по названию» и проверь вручную.

Что делать с расхождениями

  1. Скачай файл, открой в Excel. Автофильтр включён.
  2. Отфильтруй «WB дороже» / «WB дешевле».
  3. Отсортируй по «Разница ₽» — крупные расхождения сверху.
  4. Реши по каждой: поднять цену на WB, снизить на сайте, или оставить.

Как работает «Способ»

  • 🎯 по артикулу — пара найдена в первом проходе. Максимальная уверенность.
  • 📊 по названию — пара найдена во втором проходе (после неудачи по артикулу). Проверяй глазами.
  • — (пусто) — товар без пары.

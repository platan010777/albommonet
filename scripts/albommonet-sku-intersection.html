🔀 Склейка сайта × второго файла по названию

Берёт CSV сайта и xlsx, находит лист с колонкой SKU, склеивает позиции по названию с настраиваемым порогом. В итоге — пары «сайт ↔ файл 2» + сироты второго файла.

🔒 Всё считается прямо в браузере. Файлы никуда не отправляются.
🎯 Лист второго файла определяется автоматически — по наличию колонки SKU.
📊 Порог схожести названий — настраивается (по умолчанию 70 %).
💰 В колонку «Цена (сайт)» идёт «Зачеркнутая цена» из CSV сайта.

📋 Что загружаем

  1. CSV сайта ALBOMMONET.RU — эталон.
  2. xlsx второго файла — скрипт сам найдёт лист с колонкой SKU.

💡 Колонки ищутся по синонимам: Наименование, Код артикула, Зачеркнутая цена, SKU, Название товара.

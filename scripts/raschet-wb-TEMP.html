💰 Расчёт цены WB

Из СТАРТА считает цепочку: себестоимость = старт × 60% → +300 ₽ → /0.65 → /0.65 → /0.40 → округление вверх. Результат — лист «Расчёт» и лист «Для WB».

🔒 Всё считается прямо в браузере. Файлы никуда не отправляются.
💡 Локальный скрипт. Запуск через Live Server.

📋 Что загружаем

  1. xlsx с товарами — 4 колонки: артикул, наименование, ID WB, СТАРТ.
  2. Названия колонок могут быть любыми из списка синонимов, порядок — любой.
  3. Если колонка не найдена — можно указать вручную в выпадающем списке.
  4. Константы (300 ₽, %, …) — в отдельной панели, можно менять.
